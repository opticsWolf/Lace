# Archived Documentation

These documents are kept for provenance, not as current guidance. They record
reviews, implementation plans and investigations from earlier Lace releases.
They may describe removed APIs, fixed bugs, old test counts or Qt/PySide6
versions, and their paths and examples are frozen at the time of writing.

Current documentation lives in:
